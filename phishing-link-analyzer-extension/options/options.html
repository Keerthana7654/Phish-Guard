⚙️ PhishGuard Settings

General

Backend (optional)

Leave blank to use PhishGuard's built-in local detection engine only. Point this at your Spring Boot analysis service (e.g. http://localhost:8009) to enable WHOIS, Safe Browsing, VirusTotal and other server-side checks. The extension automatically falls back to local detection if the backend is unreachable.
